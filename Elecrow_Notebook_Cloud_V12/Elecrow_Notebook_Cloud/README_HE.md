# Elecrow Notebook / CrowPanel Advanced 9-inch V1.2

**סטטוס:** קוד מקור ותהליך בנייה אוטומטי; עדיין לא בוצעה קומפילציה מוצלחת או בדיקת חומרה. אין לצרוב לפני שבנייה מצליחה, ולאחר גיבוי התוכנה הקיימת.

## בלי להתקין Arduino IDE

1. בחשבון GitHub, צור Repository חדש, העלה את תוכן התיקייה הזו (כולל `.github/workflows/build.yml`).
2. עבור ללשונית **Actions** > **Compile Elecrow Notebook V1.2** > **Run workflow**.
3. אם הבנייה ירוקה, הורד את ZIP התוצרים תחת **Artifacts**. אם אדומה, הצג לי את שגיאת הבנייה ואתקן.
4. צריבה תתבצע רק אחרי בדיקת רשימת הקבצים והכתובות הנכונות. קובץ app.bin לבדו אינו תמיד מספיק למסך נקי, ומומלץ לגבות תחילה את ה־Flash הקיים. הכלי המקוון: https://espressif.github.io/esptool-js/

## האפליקציה

עמוד ציור יחיד, עטי שחור/אדום/כחול, מחק, CLEAR, SAVE ו־LOAD. שמירה מותנית במחיצת SPIFFS מתאימה. לא מתבצע פירמוט אוטומטי.

הקוד נשען על Lesson09 הרשמי של Elecrow V1.2 (LVGL 9.1). Workflow מוריד בעת הריצה קבצי יצרן וספריות; הפרויקט לא מכיל אותם ב-ZIP.

**חשוב:** בנייה בענן לא מהווה אישור לתקינות על חומרה אמיתית; עשויות להידרש התאמות לגרסאות ESP32 core/ספריות/מחיצות.
